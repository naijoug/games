## 阶段门槛

- 规则和内容检查：运行本款 Node 测试，验证题库的合法性、可解性及必要的唯一解；固定解答回放和非法操作必须覆盖。
- 页面检查：本地 HTTP 下检查桌面 1440×900、手机 390×844 和 320px 窄屏，包含输入、提示、撤销／重试、重开和完成状态；保存浏览器截图并人工查看，自动化交互辅助复现。
- 接入检查：每新增一款就同步当前页面导航、门户、README 和架构清单，运行全量当前测试、构建及站点链接检查；不将未来未实现游戏提前链接。
- 文档和提交：更新本款计划状态、此表及结果记录，再提交该阶段涉及的文件。仓库开始时仅有本对话上一轮创建的计划文档变更，纳入阶段 0。
- 变更控制：实现中如有必要调整算法或输入细节，先更新对应计划及理由；不得把未通过检查的功能标记完成。真实儿童试玩不以自动化测试替代。
