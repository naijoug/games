```bash
node --test games/*/tests/*.test.js scripts/tests/*.test.js
node scripts/build-site.js
node scripts/check-site.js
git diff --check
```

- 147 项测试通过，0 失败、0 跳过。

- 固定题库全部回放合法解答；数独和数织全部验证唯一解与指定简单推理；新增内容去重检查覆盖 9 个固定题库的题目和稳定 ID。

## 浏览器验收与复跑

使用本地 Chromium／Playwright；对构建产物搭建 `/games/` 前缀预览。每款在 1440×900、390×844、320×844 的独立浏览器上下文中检查，共 39 个主要场景；另逐款检查禁用存储和损坏存储。覆盖实际按钮与键盘操作、触摸重开、通关或关键阶段、提示、撤销／重试、关卡和模式切换、回到门户再进入游戏、无 JavaScript 页面异常、无横向溢出。

可复跑入口为 [scripts/check-kids-browser.cjs](../../../scripts/check-kids-browser.cjs)，具体场景保存在 [scripts/browser-cases](../../../scripts/browser-cases)。Playwright 为可选外部验收工具，不是游戏运行或默认 Node 测试的依赖。命令与环境变量见[根 README](../../../README.md)。

```bash
PLAYWRIGHT_MODULE_PATH=/absolute/path/to/playwright KIDS_BASE_URL=http://127.0.0.1:8766/games node scripts/check-kids-browser.cjs
```

数织的“优先指出其他行列冲突”收尾修复之后，重新运行该款四项核心测试及三尺寸浏览器场景。最终全量 Node 测试包含此修复。其他通过的浏览器场景未因纯文档调整重复运行。

逐款手机截图经过人工查看；补充检查了[机器人桌面布局](evidence/robot-1440.png)、[七巧板桌面布局](evidence/tangram-1440.png)、[迷宫桌面布局](evidence/maze-1440.png)与 320px 规律题分组。游戏大厅的 27 个入口和三尺寸布局另行检查通过：[手机大厅](evidence/portal-390.png)、[桌面大厅](evidence/portal-1440.png)。

## 实施中修复的问题与范围限制

- 为模式切换和重开增加会话隔离，清理翻牌／Simon 旧计时器；水管的旧放水动画和求解中的旧提示不能改动新局。
- 修正控件重绘后的键盘焦点、水管切关的水流残留、对称画画切回单色关的工具选择，以及数独显示偏好的保存。
- 替换迷宫、规律、对称和机器人题库中的重复内容，并加入自动去重检查。
- 七巧板首版为网格平移和 90° 旋转的入门玩法，平行四边形可翻面；不支持任意旋转。机器人支持单层重复，不支持嵌套程序。
- 求解提示有访问状态上限；超限会建议撤销或重开，不声称保证任意局面的最优解。
- 保留经典推箱子第三关“2 箱子、3 目标，所有箱子上目标即完成”的历史语义；儿童关严格箱数等于目标数。
- 本次验证是规则与浏览器验收，不是儿童真实试玩、教育效果研究、Safari／Firefox 或真机触屏认证。年龄与难度仍可根据后续真实使用反馈调整。
