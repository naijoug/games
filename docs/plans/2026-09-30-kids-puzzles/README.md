## 所有计划共同遵循的决定

### 文件与运行契约

新游戏放入 `games/<slug>/`，按以下职责拆分；各计划中的文件名为待创建目标，不代表文件已经存在。

| 文件 | 职责 |
| --- | --- |
| `game-core.js` | 无 DOM、无存储依赖的规则、状态及转换；不直接安排动画计时器 |
| `levels.js` | 有稳定 ID 的固定关卡／题目、教学文字和验证用解答；凑十改用局内生成 |
| `app.js` | DOM、键盘和触摸输入、动画、定时器、存储读写 |
| `index.html`、`styles.css` | 中文游戏说明、控件、布局与本游戏样式 |
| `tests/game-core.test.js`、`tests/levels.test.js` | 规则边界、整套题库合法性及解答回放；按实际模块设置 |

沿用 IIFE 的浏览器全局变量与 Node CommonJS 双导出，不引入 npm 依赖、构建框架或服务端。HTML 按 `levels.js → game-core.js → app.js` 加载；不依赖关卡数据的核心通过参数接收关卡，避免隐式浏览器全局依赖。随机逻辑注入 `randomFn`，便于复现。

首版使用本地 SVG、CSS 几何图形和文字，不依赖外部图片、音频、API。关卡自行设计；参考产品只用于理解玩法。暂不抽取共享儿童游戏框架，重复代码确有稳定需求后另行评估。

### 儿童操作与状态

- 页面内游戏说明、按钮及反馈用中文，每款有一个可以立即试玩的引导关；新页面设置 `lang="zh-CN"`。保留现有站点外壳，儿童样式限定在本游戏页面。
- 默认不倒计时、不扣生命、不因使用提示阻止过关。完成后显示“再玩一次／下一关”，不自动跳转。
- 主操作按钮至少 44×44 CSS px；大棋盘使用方向按钮或选中后控制，避免要求孩子点击过小格子。颜色同时配合形状、图案或文字，音效不是必需信息。
- 支持鼠标、触摸及键盘；拖动玩法必须提供“选中 → 移动／旋转／放置”的替代操作。重绘后保留合理焦点，不把整块棋盘每次变化都播报给读屏器。
- 可撤销玩法将一次有效操作记作一步；非法操作不入历史。撤销同步恢复状态、步数和胜利标记。答题类采用重试，Simon 采用重播，翻牌不提供揭示信息后的撤销。
- 切换关卡、重开、切换模式要清理定时器，并用会话标识阻止旧回调修改新局。尊重减少动态效果偏好。
- 关卡 ID 如 `maze-01` 一经发布不复用。各游戏使用独立存储键 `mini-games:<slug>:progress:v1`，仅保存已完成 ID、选项和上次关卡；首版不恢复进行中的棋盘。解析时检查版本、类型和允许值，未知 ID 忽略，损坏或禁用存储时仍可玩。现有游戏模式使用独立键，保留已有存档语义。

### 关卡、提示与计算预算

先做固定题库，所有关卡有可执行的合法解答或可验证答案。适合排除推理的数独、数织必须验证唯一解；拼图和路径类允许多解，判定不应只认样例解。

提示必须对应玩家的当前状态。穷举不放在每次渲染中；需要搜索时设置访问状态上限，异步分片运行，退出页面／重开时可取消。找不到解或超过预算时明确建议撤销／重开，不给未经验证的方向。各游戏计划指定预算与降级行为。

### 站点接入

每款新游戏接入时完成以下事项，不把未实现游戏链接提前放入门户：

1. 更新根 `index.html` 的游戏入口，使用 `./games/<slug>/index.html`。
2. 更新当前 `games/*/index.html` 的内联导航，新页面也包含当时所有当前游戏；保留当前项标记。无需接入闲置的 `src/sidebar.js`，不修改 `v1/`。
3. 更新根 `README.md` 的在线目录与本款玩法；发布 URL 为 `https://naijoug.github.io/games/games/<slug>/`。
4. 更新当前架构文档的游戏清单、总数及实际新增模块；只有游戏实施后才更新，规划阶段不能写成已存在。
5. 共享 CSS 只有确认需要时才修改。检查已有页面的内联 `!important`、按钮伪元素和大小写转换，不整段复制它们造成图形按钮失真。

### 每款的验证与完成条件

先运行该计划中的单游戏 Node 测试。新增游戏涉及导航，接入后按仓库要求运行：

```bash
node --test games/*/tests/*.test.js scripts/tests/*.test.js
node scripts/build-site.js
node scripts/check-site.js
```

浏览器通过本地 HTTP 服务检查 1440×900、390×844，以及 320px 窄屏。检查鼠标、触摸／触屏模拟和键盘操作、初始／进行中／完成状态、重开与提示、禁用存储、无横向溢出，以及从门户进入再回到门户。用 `/games/` 项目基路径验证资源和导航；静态链接检查不能替代交互验证。

每款完成时：所有本款验收项通过、题库验证通过、相关文档与导航一致，才将状态改为“完成”，并记录运行命令、结果和浏览器证据。通过后仅在新修改或发现问题时追加检查。所有计划都不包含推送或部署授权。

已新增 10 款游戏，改造 3 款儿童模式；新增固定题库共 182 关／题（含儿童推箱子 12 关），凑十另按可配完规则生成牌局。保持静态部署和浏览器／CommonJS 兼容，仅进行本地提交，未推送或部署。儿童真实试玩后的难度调整属于后续迭代，浏览器检查不能证明儿童独立使用效果。
