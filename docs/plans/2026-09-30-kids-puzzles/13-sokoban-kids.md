# 推箱子儿童模式实施计划

- 状态：草案，未实施；日期：2026-09-30。
- 目标：5–9 岁儿童从一个箱子开始学习推动和规划，失误时可撤销。
- 路径：现有 `games/sokoban/`；遵循[共同约定](README.md)，不新增路由。

## 现状与范围

`game-core.js` 内嵌 3 个经典关卡，`createGame(levelIndex=0)` 按索引创建，状态用 `Set` 保存墙、目标和箱子。`move` 检查墙／箱子但没有显式坐标边界；没有撤销或提示。页面通过 `LEVELS.length` 循环下一关。

现有第三关有 2 个箱子、3 个目标，而 `isSolved` 的语义是“每个箱子都在目标上”。本计划保留经典关卡和该历史完成语义，不在儿童模式工作中默默重写经典题目；新增儿童关必须严格箱数等于目标数。

首版增加 12 个自制儿童关：6 关一个箱子、6 关两个箱子，棋盘不超过 7×7。前几关只需直推，后续加入绕到箱子另一侧和绕障碍。默认仍为经典模式，提供明显的儿童模式切换；不加入拉箱子、传送带或新机关。

保留 `LEVELS` 导出和 `createGame(index)` 调用。新增 `kids-levels.js` 存有 ID、地图、解答的儿童题库，通过 `createGameFromLevel(level)` 建局，核心不反向依赖浏览器全局。新旧模式明确区分关卡 ID 与经典索引，重开和下一关使用当前模式的关卡集。

## 关键实现决定

- 移动和推箱前显式检查棋盘边界，未知方向无操作；这也保护旧关卡解析后的状态，不改变正常围墙地图的玩法。
- 新增 `undo`，保存有效移动前的玩家位置、箱子集合、步数、推动数和状态；克隆 Set，避免后续修改污染历史。无效移动不入历史，胜利后可撤销。
- 儿童题库校验矩形、封闭边界、一个玩家、相等且非零的箱子与目标数、合法符号和可解性。
- 提示用独立 `solver.js` 从当前玩家和箱子位置 BFS。箱子位置排序构成状态键；小地图、最多两个箱子，每批 500 状态、上限 30,000 状态，浏览器分片且可取消。找到解只显示下一步；无解或超限提示撤销／重开，不移动箱子。
- 死角提醒首版只识别非目标墙角中的箱子，称作“这个角落可能出不来了”，不宣称能识别全部死锁。提示结果必须绑定当前局面，移动后丢弃。

## 验收与验证

运行 `node --test games/sokoban/tests/*.test.js`。

- 旧调用和经典 3 关仍可创建；儿童创建不改变 `LEVELS`；撞墙、连推两个箱子和越界均不移动。
- 一次普通移动、一次推动及胜利后的撤销分别恢复正确状态；多步历史的 Set 无别名污染；重开清空历史。
- 12 个儿童关全部合法、可解且参考解回放通关；提示动作合法，死角／超限搜索有明确结果；现有第三关额外目标语义有回归覆盖。
- 浏览器完成儿童第一关、切换经典再回来、撤销推动与胜利、搜索时重开，关卡计数和棋盘保持一致；7×7 手机局面可通过大方向按钮操作。
