# 翻牌儿童模式实施计划

- 状态：草案，未实施；日期：2026-09-30。
- 目标：4–8 岁儿童从少量动物卡片开始配对，逐步增加记忆负担。
- 路径：现有 `games/memory/`；遵循[共同约定](README.md)，不新增游戏路由。

## 现状与范围

`game-core.js` 已支持 `createGame({pairCount,randomFn,deckValues})`，默认 8 对，页面 `app.js` 初始化和重开都写死 8 对。不匹配时 500ms 翻回，定时器未保存句柄；重开只清 `resolving`，旧回调可能作用于新局。

首版增加儿童模式 2／4／6 对，经典模式保留 8 对和既有规则、默认行为。儿童模式使用动物 SVG／图标，并保留可读名称；逻辑继续用稳定卡片值。未翻开的卡不能通过可访问名称泄露动物答案。儿童模式错配停留 1200ms，不做全盘预览、自动解答或排行榜。

对数切换重建牌局；保存模式和对数偏好，不保存牌面布局。初次访问维持经典模式，显著提供“儿童模式”按钮。棋盘布局按对数适配，卡片至少 44px。翻牌不提供撤销，以重试、重开代替。

## 阶段与文件

- [ ] 规则与回归：复用 `game-core.js` 的可配置对数；在 `tests/game-core.test.js` 增加 2／4／6 对完整通关、每值恰好两张、锁定期间点击无效及非法索引用例。若增加参数校验，保持合法既有调用不变。
- [ ] 生命周期：在 `app.js` 保存翻回计时器句柄及会话 ID，重开、换模式／对数时取消回调；旧回调不允许解除新局锁定或翻回新局牌。
- [ ] 儿童页面：修改 `index.html/styles.css/app.js` 增加模式、对数和图形映射，清理影响卡片图形的局部内联覆盖；用焦点位置恢复避免翻牌重绘丢焦点。
- [ ] 文档与验收：更新根 README 的 Memory 玩法；门户已有链接不变，如调整入口说明或导航则执行全站验证。

## 验收与验证

运行 `node --test games/memory/tests/*.test.js`。仅改本游戏时按单游戏规则与 UI 验证；涉及共享样式或门户／导航时再执行共同约定的全站检查。

- 2／4／6／8 对都能完整配对；经典原有测试保持通过，点击同一张不构成匹配，已匹配牌不重复计数。
- 浏览器：翻出错配后立即重开，再在新局翻两张错配牌；旧回调不应提前翻回它们。重复切换模式无残留定时器效果。
- 手机 6 对布局无横向滚动；键盘能连续翻牌且焦点可预测；背面名称只包含位置，正面与已匹配牌可读出动物名和状态。
- 刷新恢复有效的模式偏好；损坏或被禁用的存储不影响开局。

尚未实施。核心规则可直接复用，主要工作是界面和计时器生命周期。现有字母到图形的转换属于显示层，不改变卡片匹配语义。
