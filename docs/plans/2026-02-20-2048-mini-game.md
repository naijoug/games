# 2048 Mini Game Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a playable 2048 mini game in `2048/` and deploy it with GitHub Pages from this repository.

**Architecture:** Use a static frontend (`index.html`, `styles.css`, `app.js`) plus a pure game engine module (`game-core.js`) that is testable in Node. Deploy with a GitHub Actions workflow that uploads only `2048/` as Pages artifact.

**Tech Stack:** Vanilla HTML/CSS/JavaScript, Node built-in test runner, GitHub Actions Pages.

---

**Files:**

- Create: `2048/tests/game-core.test.js`

**Step 1: Write failing tests for core behavior**
